# 🏆 Битва Накоплений 2026

Веб-приложение для дружеского соревнования «кто отложит больше». Данные берутся из
**публичных сборов T-Bank** (ссылки вида `https://tbank.ru/cf/XXXX`), бот собирает
снимки по расписанию, а сайт показывает рейтинг, уровни, ачивки и динамику.

## Что показывает

- **Рейтинг** двух (или больше) участников: кто сколько накопил, медали, разрыв.
- **Прогресс к цели** сбора (кольцо + проценты).
- **Уровни и XP** — звания от «Новичок» до «Босс накоплений».
- **Ачивки** — «Первый рубль», «Сотка», «В ударе» (стрик), «Цель взята» и др.
- **Динамика**: прирост за 24ч / неделю, средний темп, прогноз достижения цели,
  стрик дней роста, мини-график.
- **Инсайты** — мотивирующие подсказки («X догоняет: обгонит за ~N дней»).

## Как это устроено

```
src/                 React + Vite + Tailwind (фронт)
netlify/lib/         общая логика:
  participants.ts    ← УЧАСТНИКИ И ССЫЛКИ (правьте здесь)
  tbank.ts           запрос к API сбора T-Bank
  stats.ts           движок: уровни, ачивки, динамика, инсайты
  store.ts           хранилище (Netlify Blobs / локальный файл)
  collect.ts         ядро «бота»
netlify/functions/
  data.mts           GET /api/data — статистика для фронта
  collect.mts        GET /api/collect — ручной сбор (для отладки/cron)
  scheduled-collect.mts  бот по расписанию (cron)
```

Источник данных — обнаруженный публичный эндпоинт:
`GET https://www.tbank.ru/api/common/v1/cm/crowdfund/info?nickname=..&crowdFundingId=..`
(резолвится автоматически из короткой ссылки сбора).

## Участники

Откройте `netlify/lib/participants.ts` и впишите ссылки сборов:

```ts
export const PARTICIPANTS = [
  { id: 'egor',   displayName: 'Егор Саныч',   link: 'https://tbank.ru/cf/10fEaUCnpCZ', accent: '#5b8cff' },
  { id: 'kirill', displayName: 'Кирилл Саныч', link: 'https://tbank.ru/cf/AJkrON7VMvB', accent: '#ff5bbd' },
];
```

Можно добавлять третьего, четвёртого и т.д. — карточки появятся автоматически.

## Запуск локально

```bash
npm install

# вариант 1: с функциями (как в проде)
npm i -g netlify-cli
netlify dev            # сайт + функции на http://localhost:8888

# вариант 2: только фронт (нужен запущенный netlify dev на :8888 для /api)
npm run dev

# проверить сбор данных без Netlify (пишет data/history.json):
npm run collect:local
```

## Деплой на Netlify (рекомендуется)

1. Залейте проект в Git (GitHub/GitLab) и подключите репозиторий в Netlify
   (**Add new site → Import**). Build-настройки подхватятся из `netlify.toml`:
   - build command: `npm run build`
   - publish: `dist`
   - functions: `netlify/functions`
2. Включите **Netlify Blobs** — он работает «из коробки» на современных тарифах,
   ничего настраивать не нужно.
3. Готово. `scheduled-collect` будет запускаться по cron (`@hourly`), накапливая историю.
   Первый заход на сайт сразу сделает первый сбор (cold-start seeding).

### Частота бота
Меняется в `netlify/functions/scheduled-collect.mts` → `config.schedule`
(`'@hourly'`, `'0 */3 * * *'` — раз в 3 часа, `'0 9,21 * * *'` — 9:00 и 21:00 и т.д.).

### Ручной сбор / защита
`/api/collect` запускает сбор вручную. Можно защитить токеном:
задайте переменную окружения `COLLECT_TOKEN` и вызывайте `/api/collect?token=...`.

## Альтернатива: бот на GitHub Actions

Если не хотите serverless-функции, используйте `.github/workflows/collect.yml`:
он раз в час пишет `data/history.json` и коммитит в репозиторий. В этом случае
уберите `data/` из `.gitignore` и настройте фронт на чтение `history.json`
(сайт можно публиковать как статику). Подходит, если дата-центры Netlify когда-нибудь
начнут ограничивать запросы к T-Bank — GitHub Actions это запасной канал.

## Заметки

- API T-Bank неофициальный (получен реверсом фронта). Для дружеского челленджа годится;
  если структура ответа изменится — правьте `netlify/lib/tbank.ts`.
- Если у сбора включено «скрывать собранную сумму», поле `collectSum` может быть скрыто —
  тогда участник увидится с 0. Для соревнования суммы лучше держать открытыми.
